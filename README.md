# Villa Giaggioli

A private website for the historic Italian estate.

## Local preview

```bash
python3 -m http.server 4173
```

Then open [http://localhost:4173](http://localhost:4173).

## Before it goes live

1. Replace `INQUIRE_EMAIL` in `js/main.js` with the real inquiry address.
2. Add photographs when you have them. Natural places to drop images:
   - the hero, beside the villa name
   - the grounds list in **Estate**
   - each house in **Stay**
3. Add the nearest town or region in the hero kicker and location section if you want it public.
